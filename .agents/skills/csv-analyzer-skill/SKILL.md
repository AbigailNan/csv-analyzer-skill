# CSV 数据分析

## 分析流程

1. 确认用户提供了可读取的 CSV 文件；如果没有，请用户提供文件或路径。读取后说明行数、列数、列名及各列的数据类型。
2. 检查缺失值：统计每列的缺失值数量和占总行数的比例。说明使用的缺失值识别规则，例如空字段；不要擅自把 0 当作缺失值。
3. 检查重复值：默认按所有列识别完全相同的行，报告除首次出现外的重复行数量；如果用户指定了用于判重的列，则按指定列检查。
4. 计算描述性统计：对数值列报告非缺失值数量、均值、标准差、最小值、25% 分位数、中位数、75% 分位数和最大值。对非数值列报告非缺失值数量、唯一值数量及最常见值和其频次。

## 结果输出

- 用简洁的中文概述数据规模、缺失值、重复值和主要统计结果，必要时使用表格。
- 统计计算忽略缺失值，但不自动删除重复行；标准差使用样本标准差。没有足够有效数据的统计项标为“无法计算”，不要编造结果。
- 只分析数据，不擅自填补缺失值、删除重复行或修改原始文件。
